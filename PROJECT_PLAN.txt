================================================================================
PROJECT OVERVIEW
================================================================================
An AI-powered file manipulation tool for Android devices. Users interact with
their Android phone through a natural language chat interface. The AI
understands file commands and executes them via ADB.

ARCHITECTURE:
[Flutter App] → [PC Server:3000] → [Ollama AI] → [ADB Tools] → [Android]
       ↑                                                      ↑
       └──────────────── Tailscale VPN ──────────────────────┘

================================================================================
KNOWLEDGE / TRAIN SYSTEM
================================================================================

Commands:
  /train file1.txt file2.md     - Learn from specific files
  /train /sdcard/Notes          - Learn from folder contents
  /forget                        - Clear all learned knowledge

How it works:
  1. /train reads files via ADB
  2. Stores content in session knowledge base
  3. Injects knowledge into every AI call context
  4. Persists for the session (survives server restart)

API:
  GET  /api/knowledge/:sessionId  - Get learned knowledge
  DELETE /api/knowledge/:sessionId - Clear knowledge

SESSION MANAGEMENT
================================================================================

- Each session has unique ID (32-char hex)
- Chat history stored in sessions/<id>.json
- Last 20 messages sent to AI (configurable)
- Knowledge base per session (via /train)
- History survives server restarts
- Sessions can be renamed/deleted
- Local caching via SharedPreferences (client)
